## 画布适配输出契约（canvas-shots/v1 · 本节优先）

> 本节为「无限画布」适配层。**与正文任何条款冲突时，以本节为准**。正文的人·物·场分离原则、原文优先三级标注、服化道场严谨、精炼但有特征、场景大白话描述全部继续有效。

### 一、输出结构（三份文档之后追加机读块）

1. 仍按正文输出三份人读文档：角色外观描述 → 道具清单 → 场景清单。
2. 文档**末尾**追加唯一一个 ```json 围栏，schema 为 `canvas-shots/v1`，`shots` 给 `[]`，只填 `locks`（见 `docs/skill-canvas-output-contract.md` §2）：

```json
{
  "schema": "canvas-shots/v1",
  "locks": [
    { "label": "锚点·角色01 林溯", "kind": "character", "prompt": "≤300 字定妆提示词" },
    { "label": "锚点·场景02 山间破庙", "kind": "scene", "prompt": "≤300 字定版提示词" },
    { "label": "道具·07 塌毁的供桌", "kind": "prop", "prompt": "≤300 字道具提示词" }
  ],
  "shots": []
}
```

### 二、锚点提示词规范（画布锁一致性靠它）

- **角色**：中性灰或纯色背景、正面全身站姿、平视、中性表情、柔和均匀主光、无剧情动作、无遮挡；≤300 字，写满六要素（年龄/性别/肤色/发型发色/五官/服装）与体态。需要多角度时拆成三条：`锚点·角色01 林溯-正面` / `-侧面` / `-背面`，构图与光保持一致，只换视角。
- **场景**：直接用正文 C3 的「正面全景微俯视大白话」，可补「约 15–25° 俯角」；≤300 字，含近景地面、左右中景、纵深远景与光线方向色温。
- **道具**：单件居中、纯净背景、多面可见、比例参照（如「约等身前臂长度」），≤300 字。
- 这些提示词是**定版图**的提示词，不是剧照：不带人物戏、不带台词、不带镜头运动。

### 三、锁定串（跨镜头逐字复用）

每个角色的外观是一段**不可改写的锁定串**：在 `locks[].prompt` 里定义一次，之后分镜技能引用本锚点时，逐字复用同一段措辞，不改字、不改语序、不增删形容词。改写一个字，跨镜头的脸就会漂。

### 四、必须过滤的噪音

正文里写给建模师/画师的内容**不进入任何提示词**，只留在人读文档：

- 建模优先级、材质表现重点、多角度描述需求、与角色/场景的配合要点
- 原文依据索引、交叉索引（角色↔道具↔场景编号）
- 输出检查清单、分析思考过程

### 五、命名

`锚点·角色NN 名字` / `锚点·场景NN 名字` / `道具·NN 名字`。标题中**不要**出现「镜头/分镜/镜/shot」，也**不要**以数字开头——画布会把它误当成待锁镜头或错号。

### 六、自检（不输出）

- [ ] 机读块只有一个、位于文档末尾、`shots` 为 `[]`
- [ ] 每个 lock 的 `label` 与正文编号一致（角色#01 ↔ 锚点·角色01）
- [ ] 角色/场景/道具 prompt 均 ≤300 字，且不含建模备注
- [ ] 同一角色在多处出现时用的是同一段逐字锁定串
- [ ] 标题不含镜头词、不以数字开头
