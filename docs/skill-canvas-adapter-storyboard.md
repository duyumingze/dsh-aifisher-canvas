## 画布适配输出契约（canvas-shots/v1 · 本节优先）

> 本节为「无限画布」适配层。**与正文任何条款冲突时，以本节为准**；正文的设计约束（光源动机、纵深主层、物理雾双检、五层色彩、质感锚点、反廉价化、情绪匹配、衔接规范、人物出现节制）全部继续有效，只是被投影进另一层输出。

### 一、三处口径裁决（正文内部冲突，画布版一律按此）

1. **不输出轴线 ASCII 图**。正文 §13.1「输出要求：必须画出轴线示意图」作废，与 §16「不输出轴线示意图」及注意事项一致。轴线约束仍是内部设计准则（正反打必须同侧），但不画图。
2. **多样性红线降为建议**。正文红线「固定镜头占比超过 30%」「全片无仰拍/俯拍」「焦段/机位/运镜种类未最大化」不再作为硬性判据：与「物理可行性 > 叙事情绪 > 多样性」冲突时，一律以物理可行性与叙事必要性为准，**不为凑机位多样性而硬塞镜头**。
3. **时长可选输出**。正文「不计算时长」保留为规格书正文的规则；机读块允许给 `duration` 建议值，但仅在确定目标模型暴露时长参数时写（见契约 §2、§8）。

### 二、输出结构（在原有规格书之后追加机读块）

1. 先输出人读规格书，格式与正文 §16 完全一致（导演备注 → 全局色调方案简表 → 逐镜头【标签】块 → 补充说明）。
2. 文档**末尾**追加唯一一个 ```json 围栏，内容严格按契约 `canvas-shots/v1`（见 `docs/skill-canvas-output-contract.md` §2）。正文里不再重复机读内容。
3. 若本次输入已带角色/场景锚点（来自资产提取技能），`shots[].locks` 必须引用对应 `锚点·…` label，并把该锚点的外形串**逐字**放入主体描述；没有锚点就省略 `locks` 字段或给空数组，绝不编造 label。

### 三、每镜 prompt 的压缩规则

把该镜头的 13 个【标签】块压成 300–600 字（硬上限 800），按以下顺序写成一到两段中文：

```
主体与瞬间（人数、姿态、正在发生的动作；多主体先声明视觉中心）
景别 + 机位高度与角度 + 焦段 + 运镜
光源类型/来源锚点/方向/衰减（无源光不合格）
色调（palette + 饱和 + 胶片 + 颗粒 + 光晕）+ 一句影调密度
纵深主层（三选一，只写选中的那种）
质感锚点（光学锐度 + 影调密度 + 媒介；人物加皮肤，浅景深加焦外）
禁项一条（无源补光 / 无介质体积光 / 数字锐化 / 蜡质皮肤 之类，按本镜实际风险选）
```

**丢弃**：台词与人声、环境音效、音桥、与上一镜的衔接、镜头功能与情绪目的、自检结论、建模式备注、场景要素分析表、交叉索引。

### 四、标题、编号、类型

- `no` 从 1 连续递增；`title` = `镜头 ` + 两位补零编号 + 空格 + ≤12 字短语（如 `镜头 03 破庙借宿`）。分镜板与一致性覆盖率靠这个编号排序与识别。
- `type`：需要运动/运镜的镜头用 `video`，静帧概念图用 `image`。
- 镜头号一旦分配不得重排；分批（>24 镜）时编号继续连续。

### 五、执行顺序（你不直接操作画布时，把这段一起交给调用方）

locks 定妆/定版出图 → recipe 一次铺开 shots → 锚点 connect 到每个镜头 → prepareGeneration（等待审批）→ **停手等用户在画布点「确认本批生成与费用」** → 生成事件到达后 preview + read_image 自评 → 不符的镜头改 prompt 重开批次。

审批红线：只准备批次，永不提交、永不绕过用户确认。

### 六、自检（不输出）

- [ ] 每个 shot 的 prompt 在 300–600 字区间，含光源来源与一条禁项
- [ ] 没有台词/音效/衔接/元信息混入 prompt
- [ ] `title` 可被 `镜头 NN` 正则解析，锚点标题不含「镜头/分镜/镜/shot」且不以数字开头
- [ ] `shots[].locks` 全部能在 `locks[]` 找到；角色外形串跨镜头逐字一致
- [ ] 单批 ≤24 镜；`duration` 只在确定模型支持时出现
- [ ] 机读块只有一个且位于文档末尾
